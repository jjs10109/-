# 对账工具说明

这几个脚本用于核对「增量模式 / 固定基线」算出来的仓位是否与真实持仓一致，以及核对指令代码。
均用 Anaconda Python（`D:\anaconda3\python.exe`）运行，需连 Wind。脚本里的项目路径已写死为绝对路径，可在任意目录运行。

## 脚本清单

| 脚本 | 用途 | 结论 |
|------|------|------|
| `对账1_股数_930至1014_连续增量.py` | 9/30 全球持仓起，逐天加 oplus1008/1009/1012/1013/1014，与真实 1014 持仓逐只比股数（多仓/融券分开） | 融券 0 差异；多仓差异全部为非网格手动交易/美股swap/货币利息 |
| `对账2_股数_930至1015_连续增量.py` | 同上，连续增量一直算到 1015，对比真实 1015 | 融券 0 差异；多仓差异均为手动/利息 |
| `对账3_股数_1014持仓快照_1015增量.py` | 1014 真实持仓 + oplus1014 建快照(只记录) + 只加 oplus1015 增量，对比真实 1015 | 多仓差异降到 8（仅手动+货币利息），证明跨天去重正确 |
| `对账4_固定基线_1014_1015_仓位零差异.py` | 直接读真实持仓（固定基线、不叠加 oplus），与持仓原始比例逐行比对 | 1014/1015 全产品多仓比例 **0 差异** |
| `对账5_指令代码Wind核对.py` | 用 Wind 逐个核对指令文件里每只股票代码与名称 | 35 只 A/H 代码全部一致 |
| `对账6_网格价格Wind核对.py` | 事后核对当前网格结果：逐只股票参考价=Wind 行情日未复权收盘、档位在±30%带内、买卖方向、目标仓位单调性、零持仓卖完档跳过；输出 `outputs_live_grid/网格价格Wind核对报告.xlsx` | 28 只参考价 0 偏差、798 组单调性 0 异常 |

## 怎么解读

- 日常跑网格以「**固定基线**」为准（每天读最新真实持仓，加 `--no-apply-oplus-trades`），仓位 100% 准确，看对账4。
- 对账1/2/3 用于证明：即使在纯增量模式，融券也 0 误差，多头误差全部来自非网格手动操作，不是网格程序问题。
- **对账6 每次重跑网格后都能跑一次**，确认每只股票价格、档位无误（需连 Wind）。
- 更换持仓/oplus 数据后，可重跑对应脚本复核。
